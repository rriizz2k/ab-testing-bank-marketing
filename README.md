# A/B Testing: Bank Marketing

Небольшой проект для отработки статистического A/B-тестирования и CI на реальных данных банковского телемаркетинга.

## Данные

[UCI Bank Marketing Dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing) — 41 188 звонков клиентам банка с предложением открыть срочный депозит.

Ключевые колонки:

* `contact` — способ связи с клиентом: `cellular` (мобильный) или `telephone` (городской)
* `y` — целевая переменная: открыл клиент депозит (`yes`/`no`)

## Метод

Сравнивались две группы клиентов по способу связи. Метрика бинарная (открыл/не открыл депозит), поэтому для проверки значимости разницы конверсий использован **z-test для двух пропорций** (`statsmodels.stats.proportion.proportions_ztest`), а для оценки величины эффекта — **доверительный интервал разницы пропорций** (`confint_proportions_2indep`).

## Результат

Клиенты, которых обзванивали через мобильный, открывали депозит почти в 3 раза чаще, чем те, кого обзванивали по городскому телефону (14.7% против 5.2%). P-value практически равен нулю — это не случайное совпадение. Доверительный интервал [8.94%, 10.06%] показывает, что разница в конверсии стабильно составляет 9–10 процентных пунктов.

**Вывод для банка:** стоит отдавать приоритет обзвону через мобильные номера.

## Как запустить

```bash

uv sync
```

```bash
uv run pytest tests -v
```
